# two-player-tic-tac-toe-223319-223328

This workspace contains a React frontend for a two-player Tic Tac Toe game.

- Container: tic_tac_toe_frontend
- Run:
  - cd tic_tac_toe_frontend
  - npm install
  - npm start
- App URL: http://localhost:3000

Features include responsive board, turn indicator, win/draw detection with highlight, move history/undo, and reset, styled with the Ocean Professional theme.
